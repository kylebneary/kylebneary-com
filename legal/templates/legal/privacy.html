Last updated: {{ now.strftime('%B %d, %Y').replace(' 0', ' ') }}

This site is a personal blog and portfolio. It doesn't have user accounts, doesn't run ads, and doesn't sell or share data with anyone, because it doesn't collect meaningful data to begin with. Here's the full picture:

What this site collects

Nothing, directly. There are no sign-ups, no contact forms, and no cookies set by this site.

What the hosting infrastructure sees

Like any website, requests to this site pass through standard web server logging on its hosting provider (Google Cloud Run). That means routine technical data — IP address, requested URL, timestamp, user agent — is logged briefly for operating and securing the service, the same as almost every website on the internet. This isn't used for tracking or shared with third parties.

Links to other sites

This site links out to GitHub, LinkedIn, and other external sites. Those sites have their own privacy policies, which this policy doesn't cover.

Cookies

This site does not set cookies or use any tracking or analytics tooling today. If that changes in the future (for example, adding privacy-friendly analytics), this policy will be updated first, and a consent banner will be added if the tool in question requires one.

Contact
